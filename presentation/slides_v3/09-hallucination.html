TS-009 · Synonym Bypass
"확인할 수 없습니다"가
좀비 캐시를 만들었다
증상
프롬프트 지시 무시하고 동의어로 거절 → answerable=true 오판정
원인
단일 패턴 매칭("찾을 수 없")에 의존 — LLM은 100% 지시를 따르지 않음
해결
패턴 리스트 매칭으로 이중 방어 — 프롬프트 + 서버 검증
Key Takeaway
LLM은 프롬프트 지시를 100% 따르지 않는다 — 형식이 중요한 판정은 이중화
