고민 ③ 3단계 캐시

동일 질문과 유사 질문, 그리고 좀비 캐시

1
Exact Match
Redis · SHA-256
질문 해시 기반 정확 일치. TTL 1시간
2
Semantic Cache
Chroma · cosine ≥ 0.95
"교육비 지원 금액?" ≈ "교육비 한도?" 자동 매칭.
별도 cache_questions 컬렉션 활용
3
Invalidation
문서 변경 시 전체 삭제
answerable=false 응답은 캐시 미저장
좀비 캐시 방지 설계 (TS-008)
"없다"는 답도 캐시에 들어가면, 문서 추가 후에도 계속 "없다"고 응답.
→ answerable=false 자체를 캐시에 넣지 않는 단순한 원칙으로 해결
