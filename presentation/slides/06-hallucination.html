환각을 프롬프트만으로
막을 수 있을까?

"문서에 없으면 모른다고 답해" — 이 지시가 얼마나 지켜지는지부터 의심해봐야 했습니다.
고민
출처 추적이 가능해도, 답변 근거가 없는 질문에서 LLM이 억지로 답하면 환각입니다. "모른다"를 정확히 말하게 하는 방법이 필요했습니다.
발견
프롬프트에 "정확히 '찾을 수 없습니다'로 답하라"고 명시했는데, 실제 LLM은 동의어로 우회하는 경우가 있었습니다.
LLM 실제 출력 (TS-009) "해당 정보는 확인할 수 없습니다" → 서버는 거절로 인식 못 함 → answerable=true 오판정
선택
프롬프트를 1차 방어로, 서버 패턴 매칭을 2차 방어로 두는 이중 방어 구조를 선택했습니다. "LLM 지시는 확률적 제어"라는 전제에서 설계했습니다.
이중 방어 — Built
LAYER 01
프롬프트 1차 방어 · 확률적 제어
SYSTEM_PROMPT에 거절 문구 고정 + 동의어 사용 금지 명시 +
Few-shot 예시 2개 (답변 가능/불가 각 1개) + JSON 스키마 강제 output_format (D22)
↓ LLM이 벗어나면
LAYER 02
서버 패턴 매칭 2차 방어 · 결정론적
_REFUSAL_PATTERNS 9종으로 답변 텍스트 검증 → 동의어 포함 시 answerable=false 재판정 
_REFUSAL_PATTERNS = (
    "찾을 수 없습니다", "확인할 수 없",
    "답변할 수 없", "답변하기 어려",
    "정보가 없", "제공되지 않",
    "포함되어 있지 않", ...
)
배운 것
LLM 지시는 확률적 제어입니다. 형식이 중요한 판정(거절 여부, JSON 구조)은 코드로 재검증하는 것이 안전합니다.
