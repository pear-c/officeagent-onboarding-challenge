"모른다" 라고
말하게 하려면?

"문서에 없으면 모른다고 답해" — 해당 지시를 얼마나 잘 따르는지 체크
고민
출처 추적이 가능해도, 답변 근거가 없는 질문에서 LLM이 억지로 답하면 환각입니다. "모른다"를 정확히 말하게 하는 방법이 필요했습니다.
발견
프롬프트에 "정확히 '찾을 수 없습니다'로 답하라"고 명시했는데, 실제 LLM은 동의어로 우회하는 경우가 있었습니다.
LLM 실제 출력 (TS-009) "해당 정보는 확인할 수 없습니다" → 서버는 거절로 인식 못 함 → answerable=true 오판정
선택
프롬프트를 1차 방어로, 서버 패턴 매칭을 2차 방어로 두는 이중 방어 구조를 선택했습니다. "LLM 지시는 확률적 제어"라는 전제에서 설계했습니다.
이중 방어 — Built
LAYER 01
프롬프트 1차 방어 · 확률적 제어
SYSTEM_PROMPT에 거절 문구 고정 + 동의어 사용 금지 명시 +
Few-shot 예시 2개 (답변 가능/불가 각 1개) + JSON 스키마 강제 output_format (D22)
↓ LLM이 벗어나면
LAYER 02
서버 패턴 매칭 2차 방어 · 결정론적
_REFUSAL_PATTERNS 10종으로 답변 텍스트 검증 → 동의어 포함 시 answerable=false 재판정
거절 판정 시 출처 반환 차단 + 캐시 미저장 (좀비 캐시 방지) 
_REFUSAL_PATTERNS = (
    "찾을 수 없습니다", "확인할 수 없",
    "답변할 수 없", "답변하기 어려",
    "정보가 없", "제공되지 않",
    "포함되어 있지 않", ...
)
배운 점
"이렇게 답해"라고 써도 LLM은 100% 지키지 않습니다. 그래서 코드로 한 번 더 잡아야 했습니다. 아직 이 2차 체크가 실제로 얼마나 발동하는지는 측정 못 했고, 이게 다음 우선과제입니다.
